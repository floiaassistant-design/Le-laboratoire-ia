# EXP-003 — Répartition des tests limites/aléatoires

**État : exécuté localement, protocole synthétique non aveugle.**

Hypothèse : à nombre fixe de 12 tests par mutation, une allocation intermédiaire couvre mieux la combinaison de défauts que des politiques extrêmes.

Pré-enregistrement pratique : comparer les ratios de 0, 3, 6, 9 et 12 positions réservées aux tests de frontières. Le reste du budget est alloué à l'exploration aléatoire ; lorsqu'il n'y a pas assez de frontières, le reliquat retourne à l'aléatoire. Fixer le ratio qui maximise le taux global sur 11 mutations déjà connues, avec départage en faveur d'un plus petit nombre de tests ciblés. Évaluer ce ratio contre 0 et 12 sur six nouveaux défauts synthétiques, en utilisant une graine distincte. Un oracle compare la fonction attendue à une version intentionnellement erronée.

Résultats des 200 répétitions sur 11 cas connus :
- 0 frontières : 574/2200 = 26,09 %.
- 3 frontières : 1625/2200 = 73,86 % (**sélection**).
- 6/9/12 frontières : 1518/2200 = 69,0 %.

Sur 6 cas distincts (1200 évaluations par politique) :
- 0 frontières : 371/1200 = **30,92 %** ;
- 3 frontières : 846/1200 = **70,5 %** ;
- 12 frontières : 772/1200 = **64,33 %**.

**Interprétation limitée :** dans ce jeu artificiel, réserver quelques tests aux limites puis explorer le reste est utile. Aucun modèle de langage n'a été appelé, et aucune performance de multi-agent n'est mesurée. Les défauts ont été créés par la même personne qui a conçu les politiques ; un second corpus réellement externe est nécessaire.

Commandes : `python run_hybrid.py` et `python -m unittest discover -v`.
